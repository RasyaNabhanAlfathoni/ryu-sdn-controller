### Flow System Overview
## 1) Fase Registrasi
# Agent Node → Ryu Controller (Device Registration)
#     ↓               ↓
# agent_register.py → controller.py (/devices POST)

## 2) Fase manajemen
# Web Dashboard → Ryu Controller → Agent Node (Command Execution)
#       ↓               ↓               ↓
#    Browser → controller.py → server_api.py → agent_api.py → Local Commands

# Infrastruktur
# - VM Ryu manager (ryu_manager and dashboard)
# - VM Ryu agent (ryu_agent and ryu_agent_api)
